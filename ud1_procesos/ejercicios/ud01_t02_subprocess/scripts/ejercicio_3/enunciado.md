
# 3. check_repo.py: Comprobar el estado de un repositorio Git.

-   El programa ejecuta varios comandos Git para comprobar si hay cambios
    pendientes, obtener información sobre el último commit y actualizar
    la información del repositorio remoto mediante git fetch.

-   Finalmente, muestra un resumen del estado del repositorio e informa
    de los errores que puedan producirse durante la ejecución.
